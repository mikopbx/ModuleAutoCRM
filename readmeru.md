# ModuleAutoCRM для MikoPBX

Модуль интеграции для синхронизации истории звонков MikoPBX с системой AutoCRM.

## Обзор

ModuleAutoCRM автоматически собирает записи о звонках из вашей системы MikoPBX и загружает их в AutoCRM. Модуль отслеживает входящие и исходящие звонки, сопоставляет их с пользователями CRM и предоставляет URL для прослушивания записей разговоров.

## Возможности

- **Автоматическая синхронизация звонков** - Сбор звонков каждую минуту из CDR и загрузка в CRM
- **Синхронизация пользователей** - Ежедневная синхронизация пользователей CRM с их телефонами и внутренними номерами
- **Управление автосалонами** - Синхронизация автосалонов из CRM для корректной привязки звонков
- **Прослушивание записей** - Безопасные URL для воспроизведения записей звонков в CRM
- **Повторные попытки** - Автоматическая повторная загрузка при ошибках (до 3 попыток)
- **Веб-интерфейс** - Панель администратора для настройки и мониторинга

## Требования

- MikoPBX версии 2023.2.150 или выше
- PHP 7.4 или PHP 8.x
- Активный аккаунт AutoCRM с доступом к API

## Установка

1. Скачайте ZIP-файл модуля
2. Перейдите в Панель администратора MikoPBX > Модули > Управление модулями
3. Нажмите "Установить из файла" и выберите ZIP
4. Включите модуль после установки

## Настройка

### Основные настройки

Перейдите в **Модули > AutoCRM** в панели администратора MikoPBX.

| Настройка | Описание |
|-----------|----------|
| **URL API** | Адрес сервера AutoCRM API (например, `motorland.autocrm.ru`) |
| **Токен API** | Bearer-токен для аутентификации (получите в AutoCRM) |
| **Автосалон по умолчанию** | Автосалон для звонков, если у пользователя нет назначенного |
| **Протокол АТС** | HTTP или HTTPS для URL записей |
| **Хост АТС** | Публичный адрес вашего сервера АТС |

### Параметры синхронизации

| Параметр | Описание |
|----------|----------|
| **Включить синхр. пользователей** | Автоматическая синхронизация пользователей ежедневно в 3:00 |
| **Включить синхр. звонков** | Загрузка звонков в CRM (каждую минуту) |

### Ручная синхронизация

Вы можете запустить синхронизацию вручную:
- Нажмите "Синхр. пользователей" для загрузки пользователей из CRM
- Нажмите "Синхр. автосалонов" для загрузки автосалонов из CRM
- Отдельные звонки можно загрузить, нажав на их статус на вкладке "Звонки"

## Как это работает

### Сбор звонков

1. Каждую минуту модуль сканирует CDR MikoPBX на наличие новых звонков
2. Звонки группируются по `linkedid` (идентификатор разговора)
3. Модуль определяет пользователей AutoCRM, участвующих в каждом звонке
4. Внутренние звонки (обе стороны - внутренние номера) пропускаются
5. Создаются записи о звонках со статусом "ожидает"

### Загрузка звонков

1. Для каждого ожидающего звонка модуль:
   - Находит пользователя CRM по его внутреннему номеру
   - Определяет направление звонка (входящий/исходящий)
   - Формирует публичный URL для записи
   - Отправляет данные звонка в AutoCRM API
2. Успешно загруженные звонки получают статус "отправлен"
3. Неудачные загрузки повторяются до 3 раз

### Сопоставление пользователей

Пользователи сопоставляются по:
- Внутреннему номеру (например, "201")
- Мобильному телефону
- Рабочему телефону

Номера телефонов нормализуются (последние 10 цифр) для точного сопоставления.

## Вкладки в панели администратора

### Вкладка "Пользователи"

Отображает всех синхронизированных пользователей CRM:
- Имя и контактная информация
- Назначенные автосалоны
- Внутренний номер
- Статус активности

### Вкладка "Автосалоны"

Показывает все автосалоны из CRM:
- Название салона
- Адрес
- Контактный телефон

### Вкладка "Звонки"

Список синхронизированных звонков:
- Дата и время
- Направление (входящий/исходящий)
- Номера телефонов
- Статус (отвечен/пропущен)
- Статус синхронизации (ожидает/отправлен/ошибка)

Нажмите на статус синхронизации для ручной загрузки или обновления звонка.

## Прослушивание записей

Модуль предоставляет безопасные URL для записей в формате:
```
https://{pbx_host}/pbxcore/api/modules/ModuleAutoCRM/records?view={recording_path}
```

Особенности:
- Поддержка HTTP Range запросов для перемотки
- Поддерживаемые форматы: MP3, WAV, WebM
- Прямое воспроизведение в браузере

## Устранение неполадок

### Звонки не синхронизируются

1. Проверьте, что "Включить синхр. звонков" активировано в настройках
2. Убедитесь в корректности токена API
3. Проверьте логи модуля: `/storage/usbdisk1/mikopbx/logs/ModuleAutoCRM/`

### Пользователи не найдены

1. Запустите ручную синхронизацию пользователей
2. Убедитесь, что у пользователя есть телефон или внутренний номер в CRM
3. Проверьте статус пользователя (должен быть "активен") в CRM

### URL записей не работают

1. Проверьте, что "Хост АТС" - это публичный адрес вашего сервера
2. Убедитесь, что "Протокол АТС" соответствует настройкам сервера (HTTP/HTTPS)
3. Проверьте, что файл записи существует на диске

## API-эндпоинты

Модуль предоставляет REST API:

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/pbxcore/api/modules/ModuleAutoCRM/records` | GET | Воспроизведение записи |
| `/pbxcore/api/modules/ModuleAutoCRM/sync-users` | GET | Запуск синхр. пользователей |
| `/pbxcore/api/modules/ModuleAutoCRM/sync-calls` | GET | Запуск синхр. звонков |
| `/pbxcore/api/modules/ModuleAutoCRM/sync-salons` | GET | Запуск синхр. автосалонов |
